# dev/

Unlisted work-in-progress pages. Nothing here is linked from the main site,
every page carries a `noindex` meta tag, and there is deliberately no
`dev/index.html`, so `/dev/` itself serves a 404 instead of a listing.
Share URLs under this directory directly with the people who need them.

Note that this repository is public, so paths under `dev/` are visible to
anyone browsing the source — this convention hides pages from search and
casual visitors, nothing more.

Current contents:

- `psoc-tutorial/` — draft web walkthrough of the ECE 302 PSoC 5 tutorial (Tom)
